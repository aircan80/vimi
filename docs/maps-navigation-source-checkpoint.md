# Maps navigation source milestone 1

Implementation checkpoint for review, not UI/runtime approval. Optional `BuildLocationMaps.navigation(Cancellation)` defaults to an explicit UNSUPPORTED result, preserving old providers and constructors. `LocationMapsService` schedules the projection on its existing bounded worker and uses its existing cancellation, completion, close/drain, and borrowed-dependency ownership rules.

The endpoint only captures existing prepared-local UiMap/UiMapAssignment graphs. It does not call schema/page/get/preparation methods, download, decode a missing table, or fall back to a generic provider. Each scan uses the approved strict ReadLimits profile and requests one row. Exactly one capture is held at a time and closes before the next source opens. After all scans, every positive source is recaptured and its detached stamp compared before publishing. No new persistent graph cache is retained in this milestone: each request scans and validates anew.

`MapNavigationSourceTypes.Result` returns graph completeness, at most two detached source stamps, and fixed diagnostic codes (maximum64,128characters each). The graph retains build/locale scope; source stamps contain table CK/layout, prepared graph identity, source/schema SHA-256, and row count. Canonical record/list field framing bounds each fingerprint input to16KiB before string encoding; no Java record toString/hashCode is used. No schemas/pages/receipts escape into the result. A native verified issue channel is required; unknown legacy channels are explicitly unsupported.

The strict raw row/block/cell/shape limits are enforced by the shared formats-tables/generated-store reader. The separate raw transient allowance is4MiB logical. The projected stage charges at most16MiB before adding nodes/assignments, including the source-rebinding copies needed to propagate final PARTIAL evidence. The graph's separate16MiB accounting remains unchanged. One prepared-table reader's open manifest/certificate/schema metadata is a separate formats-tables ledger: the underlying open path still admits64MiB manifest and16MiB metadata JSON, not a pre-open Maps heap guarantee. Closing each capture bounds concurrent ownership, not process RSS or lower subsystem cache retention.

Malformed optional Parent/System/Flags/Type/Visibility/name values preserve the known map ID with unknown fields and propagate PARTIAL into graph Scope/TableRead, so dependent Regions stay LIMITED. Invalid assignments are omitted with PARTIAL evidence. Limited cell placeholders are marked unreadable, never interpreted as zero. Unsupported/unavailable assignments preserve map names/direct switching. Exhausted strict row or projection limits refuse the result; no biased partial hit geometry is published.

No artwork, floors, tile endpoints, UI, overlays, or image acquisition are implemented here. Floor qualification remains a future gate. This milestone does not invalidate or change the existing sidebar's raw-row/artwork caches because it never reuses them.
