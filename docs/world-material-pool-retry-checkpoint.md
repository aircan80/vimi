# Typed source-pool retry wake correction

The hosted Mac pressure test exposed a real scheduling edge as well as a time-based test assumption. An actual MATERIAL_POOL refusal completes its producer result before child CANCEL_UNUSED/CANCELED/CREDIT work necessarily retires. Recording blocked parent capacity at that moment allowed the refusal's own late CREDIT to trigger another identical source attempt with a frozen retry clock. Same-resident camera presentation also incremented the generic presentation revision, although no source owner had retired, and could repeat the pressure attempt every frame.

Only a clean, correlated bridge source refusal at finite site MATERIAL_POOL now uses source-pool backoff: retry after500ms, new demand, or actual successful source-entry retirement. Parent capacity changes and resource-neutral camera frames do not indicate that this pool regained credits. The typed flag resets before the next producer; all parent/file pressure and12-owner presentation/credit wake behavior remain unchanged. Actual source retirement has a separate actor-owned revision incremented only after entry source close succeeds.

The former50×2ms settling loop is replaced with a test-only authored child gate before unused-credit acknowledgements. The actual source-pool refusal is observed while that gate is held; the test releases late CREDIT, fences the real controller actor, and proves no new reservation at the frozen clock. After releasing the actual held pool reservations, it again fences the actor, proves no demand/parent-event shortcut, and advances only the existing test clock to recover the genuine source/packet. A second fixture accepts a real same-resident camera frame while remaining actual pool credits are held and proves that frame cannot create another reservation.

Causal controls: original implementation fails the late-credit reservation identity assertion; restoring only presentation-based pool wakes fails the same-resident camera assertion. Fixed full controller suite passes. Logs are private under `<scratch>/controller-pool-{causal-red,camera-causal-red,causal-fixed,final-check}.log`.
