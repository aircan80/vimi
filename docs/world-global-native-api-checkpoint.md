## Fixed implementation boundary

Next implementation is a package-private `BgfxGlobalWmoRenderer` implementing `GlobalWmoNativeScene`. Its only construction entry will be `static BgfxGlobalWmoRenderer upload(GpuGlobalWmoSceneFile.Decoded decoded, BooleanSupplier canceled) throws IOException`. The actual private decoded file output is adopted at method entry, on the caller's creating native thread; callers must relinquish concurrent access/close. It is structural data, never game-source authority. Constructor failure/cancellation closes every partially created handle, staging owner and adopted Decoded; there is no retry or second payload owner. A context owner must validate capabilities/shaders and establish one standalone context before calling upload; no native/context operation is introduced by this pure checkpoint.

Upload copies XYZUV into one direct851968B mesh block, using20B vertices and uint16 global indices. `bgfx_copy` gives independent queued copies (at most851968B mesh total); reuse/free staging only after each copy call returns. This uses no make_ref callback or delayed staging lease. Each image uses one reused262144B direct block; copied queued image aggregate is at most4718592B across all18 images, charged conservatively for the full scene even though actual driver release is not observable. Never describe these upper-bound counters as current driver residency. The private CPU mesh/images remain adopted until close; release is not assumed as a budget credit. There are no normals/colors, per-batch mesh duplicates, atlas/mip generation or image clone/getter copies. Scalar private Decoded reads populate staging directly.

`draw(GlobalWmoCamera)` uses the owner's already configured SEQUENTIAL view0/target without clear, framebuffer change, context creation or frame advancement. Groups and batches are drawn in canonical source order. Position/UV-only shaders use own `u_global*` namespace: corrected origin0 camera/model-to-eye plus reversed infinite-far projection, D32F clear0/strictGREATER/write, two-sided opaqueRGB, repeat U/V, linear min/mag, mip0 only, no sRGB conversion, lighting or fog. Homogeneous-depth backends remain unavailable; no LESS fallback. Initial camera scans actual validated vertex bounds on the owner thread and uses `GlobalWmoCamera.initial`; the bounded inspection framing can clamp at8192 and does not promise a client entrance, floor, collision or full framing for every extreme admissible box. Near remains0.5. Source D transform is already applied in G2; no extra permutation/negation occurs in upload.

All native entrypoints, stats and close require the creating thread. Close issues destruction and frees its direct/CPU owners; it is NOT an actual context/drain receipt. The separate proof/context owner must first retire its submitted draw/readback tickets, then close renderer resources, advance their actual retirement and call actual bgfx_shutdown before a successor context. It cannot reuse this scene after close or replace it in place. Unknown allocation/runtime errors propagate after attempt-all local cleanup; canceled work is never reported READY. No source callbacks or arbitrary provider calls occur under renderer ownership metadata locks.
