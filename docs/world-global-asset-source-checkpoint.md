# G1 global WMO source manifest checkpoint

This implements only the source phase of `world-global-asset-factory-next-slice.md` and its synchronous-decoder correction. It does not create a global renderable, mesh snapshot, image cache, packet, public facade, or GPU scene. The G2 parent/child allocation grant remains separate.

`WorldGlobalAssetFactory.inspectSources` accepts a live private `WorldGlobalScopes.GlobalScope` and comparison-only Map/MODF ordinal/UID selector. The existing engine rereads the actual WDT, validates its zero-MAIN/zero-MAID global declaration, and selects the root from its private parsed MODF. Only the fixed factory interprets actual root GFID and MOMT words to select group/image candidates. Candidate byte access and descriptive receipts alone confer no ancestry authority. No asset identifier is hardcoded into positive qualification.

The closed `GLOBAL_UNLIT_OPAQUE_RGB_V1` source recipe admits MOHD flags5/noLOD, 1–8 unique GFIDs, 1–24 actual MOMT records with shader0/blend0 and the specified unused operands zero, at most18 distinct diffuse images, and the documented five raw group flag combinations. Raw colors/groupType, portals, MOCV, MLIQ, lights, doodad declarations, and chunk descriptors remain recorded facts. They do not grant client lighting, liquid, doodad, portal culling or floor support. Overlapping MOBA spans, extra UV streams, unsupported chunks/material operands and contradictory stream declarations refuse qualification. Counts distinguish all raw triangles from only MOBA-covered triangles.

The factory validates finite position, normal and UV scalars through same-thread guarded `WmoGroupSpans` access, bounds against actual root/group boxes, and nonoverlapping material-qualified draw spans. It emits streaming canonical position/UV/index/span digests, not retained mesh arrays. Full consumed-body SHA also binds intentionally ignored raw operands.

Each image is preflighted under64KiB compressed,256×256 and aggregate1,179,648-pixel limits, then decoded synchronously through the existing strict BLP core. Only immediate `AssetSource.bytes` is used. BC1 must decode entirely opaque. BC3 retains original RGB/alpha statistics and original RGBA SHA, then deliberately forces alpha255 for a separate opaque-RGBA SHA under actual opaque MOMT semantics. The original BC3 image is never claimed opaque. Decoded `Image`, its getter copy and raw bytes die inside that image phase before another raw source opens.

The engine reserves one raw owner before stat/open/allocation: root/image64KiB, group1MiB, at most1root+8groups+18images. All read streams require COMPLETE/no holes, bounded actual length, exact consumption and explicit -1 EOF. Unknown pre-read declared size stays null; actual consumed length and enforced cap are separate. Every source is checked immediately after consumption; after the writer callback all derived bindings are rechecked FIRST, then fresh native Map/strict-EOF and WDT authority are validated LAST. The original operation's post-cancellation-drain scope/health/external-token gate still applies before R transfers. Unreturned R is closed on final failure. A callback that creates R and throws before returning owns its local cleanup.

The immutable manifest contains only bounded detached declarations, raw material words, group/image scalar facts and at most27 derived receipts (28 including WDT). No raw/group/Image/source-service graph survives a lexical phase. The manifest is descriptive and no positive factory accepts it as authority. Its borrow is same-thread and expires even on failure. Existing declaration-only APIs retain their behavior. Two finite refusal sites distinguish unsupported asset profile from changed consumed binding; malformed parser/EOF contradictions and unknown failures remain fatal.
