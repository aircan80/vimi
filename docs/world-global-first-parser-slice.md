# First global-instance implementation slice: bounded group spans

Proposed for review before production edits. This follows the allocation audit in `world-global-opaque-rgb-profile-proposal.md`. It is independent of terrain GUI/public packet transport and creates no positive global source/renderable capability. Keep global admission/Map proof extraction, image policy, aggregate mesh, codec and native pass for later reviewed slices.

Add ONE new `formats-world` raw API, provisionally `WmoGroupSpans.withGroup(byte[] raw, BooleanSupplier canceled, Consumer<Borrow> use)`. It parses an already caller-owned≤1MiB WMO17 group, then invokes a synchronous same-thread callback; clears all input/span references and expires its private-constructed Borrow in finally. No network/table/service/executor/cache ownership and no generic writer output are introduced. Raw bytes are untrusted structural input; constructing this view never authorizes file resolution or a BASIC rendering recipe.

The first API profile has fixed ceilings16,384vertices/16,384raw triangles/64MOBA batches/one UV stream/one MONR/optional one MOCV,≤256chunk descriptors, and≤64KiB detached metadata including array/list/header overhead. Validate source length/chunk spans/singletons/counts/work before allocating descriptors. Two passes over the SAME raw owner are allowed; no raw-body clone, float normal/position/UV arrays, int-index array, MOPY/MOCV copy, whole-file digest buffer or retained facts graph. Source/raw views stay inside callback; do not advertise a returned structural positive object. Existing WmoFormats standard/basic methods and their caps remain unchanged.

Borrow exposes scalar header/counts and bounded descriptors; read-only primitive/raw span access is synchronous only. MOVT/MONR/MOTV return read-only views into the raw little-endian storage; MOVI exposes unsigned16 index access or a ShortBuffer rather than an expanded int[]. MOPY and MOCV remain bounded byte spans. No interleaved20B output is allocated by this API; a later private global factory will stream position/UV and indices into its ONE owned aggregate. Validate all position/UV/normal float operands finite as raw parser safety, exact lengths/count agreement, indices<vertexCount and batch vertex/index ranges; do not normalize or impose source-lighting semantics. Unit-normal and material/group feature policy remain explicit factory concerns, never parser positivity.

Preserve unknown chunk tags/lengths as bounded unparsed descriptors. Preserve MLIQ presence/span without interpreting fluid type/height or allocating a liquid grid. Validate optional MOCV length exactly4×vertexCount without treating its alpha as opacity. Require raw MOPY exactly2×triangleCount. MOBA span overlap/partition is a rendering profile concern; raw API retains valid ranges, including unbatched inventory, and bounds batch index inspection work. Future global factory rejects overlaps, draws exact spans and reports raw vs drawn totals separately. No raw group can be called a floor or assigned a map identity.

Authored fixtures must verify detached counts/readonly buffers, absent/duplicate/misaligned/truncated streams, oversized source/vertex/triangle/batch/chunk/metadata counts BEFORE copies, nonfinite values/index/batch range errors, MOCV optional length, MLIQ/unknown preservation, cancellation in both scan/access loops, callback throw/expiry, and unsupported cross-thread access. A deliberately asymmetric fixture proves raw axes stay unchanged. Instrument or expose test-only allocation counters proving zero mesh/normal/color payload arrays and≤64KiB descriptor reservation; counters describe actual owners, not simply final DTO size.

Read-only actual source validation may then compare all8Onyxia groups against the existing RAW facts parser:23,076vertices/31,219raw triangles/59MOBA spans/7MOCV/3MLIQ, same per-stream digest and actual bounds. Use original/prior stores read-only and private scratch only, no acquired assets in Git. Compare raw span contents without constructing all8old facts graphs simultaneously. Actual match proves raw extraction only; strict BC1 still refuses BC3 image128111, and global source/native/GUI support remains absent.

Review boundary: implement ONLY this new RAW spans API+authored tests after approval. Do not add global-specific IDs, source engine changes, public BuildWorld method, packet/shader/native code, parser cap raises or an opaque-RGB positive factory. Subsequent slice will qualify separate MAID-free actual Map/WDT/global admission with serial inputs/final-all-bindings after an API checkpoint; its Map stamp extraction must preserve the existing terrain engine's semantics and close fixes.
