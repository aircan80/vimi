# Guarded raw WMO group spans

Implementation of the independently scoped parser slice after `2e30953`, with the review correction that ordinary NIO buffers cannot be revoked. Only NEW `WmoGroupSpans` and authored tests are added; existing WmoFormats/WorldFormats/WdtSceneFacts, source engines, profiles, terrain/exterior caps and native/GUI code are unchanged. This API is raw structural extraction, never a global source/renderable capability.

`withGroup` accepts one caller-owned/exclusively frozen≤1MiB WMO17 group and invokes one synchronous callback. Fixed limits:16,384vertices/raw triangles,64batches,256chunks,one UV/MONR stream,optional singleton MOCV/MLIQ and64KiB conservative metadata reservation. Length/singleton/count/batch work limits precede descriptors. It validates finite raw operands, stream counts/index and declared batch ranges, but preserves raw axes/material bytes/unknown flags/tags, unbatched/overlapping spans and optional MLIQ bytes without a rendering/opacity/liquid policy.

Private-constructed guarded Floats/Indices/Bytes expose only scalar size/get operations, never arrays/buffers. Every read checks active lifetime/same caller thread/cancellation. Each saved span holds its OWN raw/cancellation references, both explicitly cleared in finally on success or failure; it has no parser/borrow/source-owner backreference. A saved span cannot bypass expiry through a saved NIO alias. Borrow clears all references too. The original byte array remains caller owned; caller must not mutate it during this synchronous operation. No position/normal/UV/index/MOPY/MOCV/MLIQ payload arrays or clones are allocated. ByteBuffer is internal parser-only and aliases that same raw owner.

Metadata reservations are explicit conservative rows:4096fixed,96perchunk,512groupheader,512perbatch,256perguardedspan. The maximum combined shape has256chunks/64batches/seven guarded spans, reserving63,744B<65,536B, including builder/immutable-list overhead. This is a logical ownership allowance, not JVM/RSS measurement. Detached immutable scalar headers/descriptors remain bounded if a caller keeps them; they carry no payload or source positivity.
