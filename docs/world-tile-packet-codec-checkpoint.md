## Structural API/ownership

`WorldStreamTileFile` will expose package-private typed Header/SourceTuple/MipEncoding/Outcome/Reason and Expected(session nonce/scope,transaction,lease,length,fullSHA). `read(Path,Expected,BooleanSupplier canceled)` opens only expected basename tile-<tx>.wst in the caller-owned private session directory, rejects symlinks/nonregular/incorrectsize, and uses ONE FileChannel for streamed digest+decode. Validate headernonce/scope/tx/lease/counts/length/reserved/tuple metadata BEFORE geometry or atlas allocation. FullSHA covers actual complete file bytes; native geometry SHA is separate. No verify-then-reopen race. Invalid input throws a bounded IOException and publishes nothing; cancellation stays cancellation.

Read owns at most one raw geometry pair and one defensive immutable TerrainScene.Tile pair:2×1,231,872=2,463,744bytes already charged by the approved hot ledger. TerrainScene.Tile.copyOf makes exactly ONE pair of copies, not a WorldFormats.Terrain intermediate followed by anothercopy. Retire raw arrays before optional atlas allocation/qualification. Atlas is one owned byte[1,048,576], exposed read-only; never construct TerrainTileAtlas and clone another megabyte. Packet input is one64KiB buffered stream plus4096header, included in existing2×64KiB scratch allowance. Smallheader/tuple DTOs are charged to the2MiBmetadata allowance. Returned Payload owns only immutableTile+optional atlas and detached bounded metadata, not input arrays/channel/wholefile bytes. No fullpacket byte[] or bytebuffer exists.

Write borrows an existing immutable Tile and optional synchronous read-only atlas/binding, validates first, streams header/geometry/atlas with bounded scratch into CREATE_NEW unadvertised scratch, computes fileSHA from the same bytes, closes/drains then atomically renames within the owned directory. No non-atomic fallback/overwrite; failures remove unadvertised files. Publication to child remains caller responsibility AFTER source admission finalchecks; codec success never authenticates sources. Cancellation checks apply per bounded input/write chunk and qualification scan, never on FX.
