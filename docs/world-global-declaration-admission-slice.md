## Proposed package-private API

Add NEW `WorldGlobalScopes` owned by a future WorldService capability, with no public facade in this slice:

```
WorldGlobalScopes(BuildTables tables, BuildFiles files);
GlobalScope create(WorldService.MapInfo mapIdComparison, Cancellation external);
void activate(GlobalScope actualOwnedReplacement);
<R extends AutoCloseable> R withRecordedDeclaration(
    GlobalScope actualScope, Selection comparison, Cancellation external,
    DeclarationUse<R> use);
boolean isKnown(GlobalScope actualScope); // metadata only
CompletableFuture<Void> closeAsync();
```

Selection has ONLY mapId/modfOrdinal/expectedUnsignedUid. No root/group/image ID, placement matrix, source stamp or positive boolean is accepted. GlobalScope's constructor is private and it carries only owner/generation/mapId/WDT identity/scope digest. Its engine retains at most one current+one replacement proof. Each proof has the actual private WorldMapProofs.Binding, WDT id/CK/consumed length/nullable BEFORE-stat length/1MiB limit/full-body SHA, actual MODF declaration SHA and detached scalar fields including seven MPHD words. Use static nested records/classes so detached values retain no engine.

DeclarationUse receives a private-constructed same-thread expiring Borrow: bounded descriptive namespace/map authority/scope/WDT/declaration data and recorded root reference, with no raw input buffer or generic readDerived method. Expiry clears every proof/token/service reference. Detached facts may escape as descriptions; they cannot authorize later root reads or mint a renderable. R is an arbitrary owned UNADVERTISED resource, not source-positive packet data. Caller closes every unreturned allocation before R exists; engine owns R only from callback return through final checks and transfers it on success. After successful transfer, this engine owns no caller resource/presentation payload; the later closed global factory will define those owners separately.

## Exact create and callback transactions

One-active admission spans ALL steps, including callback, returned-resource cleanup and lower cancellation drain. Busy is detected before capture/stat/open. All IO, user callbacks, resource close and cancellation dispatch run offFX/outside metadata monitors. No extra source executor/cache or per-binding watcher.

`create`: actual maps.bind(mapId)→bounded complete WDT read using the actual numeric WDT ID only→both raw scans+strict declaration profile on that body→compute SHA/detach tiny proof→RETIRE raw input/facts→maps.revalidate (including fresh strict EOF/partial witness/source checks)→fresh WDT identity check→install replacement under short metadata lock and latest owner/generation check. Existing current remains valid unless its own proof is observed invalid. After the new Map bind succeeds, deliberately retire ONLY the previous replacement under the metadata lock BEFORE constructing/reading the new WDT proof, matching the existing terrain engine's two-proof bound. A later failed candidate leaves current intact and does not resurrect that stale replacement. Until Map bind succeeds, no replacement is changed. MapInfo's name/type/directory/WDT fields are comparison decorations, never authority.

`withRecordedDeclaration`: resolve this engine's current OR replacement token→maps.revalidate initial proof→reread the actual WDT under expected id/CK/length and≤1MiB cap→rescan SAME bytes and compare actual whole SHA/declaration SHA/scalars/profile with the registry proof→RETIRE raw input/facts→invoke callback with a private metadata-only Borrow→expire Borrow→fresh maps.revalidate/strictEOF +fresh WDT positive identity check→seal cancellation requests and wait actual cancellation-dispatch completion while still owning R→final external/lifetime cancellation, healthy source and known owner/generation gate→transfer R. The transfer linearization is this FINAL post-drain gate, not the earlier source-stat check; a close during cleanup cannot be bypassed merely because the cancellation lane has sealed. Thus callback output cannot precede final source proof, and repeated calls do not merely replay a caller GlobalObject or trust a WDT stat without ever consuming its body in that operation.

Source read reserves ONE live input before open/byte allocation, maxOpenInputs1/maxLiveBytes1MiB. Check known before-stat length before open, actual complete/no-hole stream length against cap/known length before allocation, read exactly consumed bytes with bounded EOF probe, fresh id/CK/known-length after read. Preserve null BEFORE-stat length as null even after enrichment. No source-compatible fallback to filenames, generated/native repair, wide rows or zero/neutral pixels. Map helper's already reviewed native capture/limits/EOF/partial-domain/c995 behaviors remain unchanged; use it directly, never create a tile scope/readMaid.

Match independently reviewed f0e2137 end-ownership semantics: retain R locally through input/admission expiry, cancellation sealing, ACTUAL dispatch completion and the final gate. If validation/callback/cancellation already failed, close R BEFORE awaiting lower callbacks, because a callback may itself require that R close to finish. If dispatch/end fails only after the body looked successful, close the still-unreturned R INSIDE the active guard; never detach it into a return statement whose finally can fail without an owner. Preserve original+cleanup failures in an ordinary fatal wrapper; an exception shaped like cancellation during cleanup is not clean cancellation or a typed refusal. Finally always clears working/cancel-child only AFTER R cleanup and real dispatch drain. Sticky cleanup fault clears proof registry and denies new work as fatal; new borrows/handoffs must check health BEFORE translating an unknown/retired token. Existing entered immutable metadata callbacks may finish pinned snapshots. No publication, GPU permit release or source-positive holder is authorized by a failed future or a generic R/metadata object.

## Lifecycle, precise refusal and cancellation contract

Reuse the reviewed source cancellation shape: a private per-operation linked child token; external/lifetime stop coalesces into at most one off-caller dispatch; lower callbacks outside locks; end seals and waits actual callback dispatch before releasing source guard. This is source-layer cancellation ownership, not permission for a seventh parent transport IO worker. One operation means at most one such dispatcher; none per file/scan/frame. The engine starts no new autonomous source worker.

`closeAsync` invalidates registry/blocks new work immediately under a short metadata lock, requests active cancellation BEFORE any foreign returned-R cleanup, and returns copied actual-drain completion. It waits real operation/callback/input/R-cleanup/cancellation-finally, never completion-request alone. Successful R from an already completed transaction belongs to caller and has no engine-owned payload to retire. Already-entered declaration callbacks may finish reading detached snapshots through close, but final checks reject transfer and close any returned R. Current+replacement proof metadata is cleared; detached scopes/facts cannot reactivate it. Own retired scope is explicit invalidation; foreign owner/caller selection mismatch remains fatal.

After the source author's origin contract freezes: actual busy→RETRY_LATER; valid but outside first declaration shape→CAPABILITY_UNAVAILABLE at a NEW explicitly reviewed global-declaration site; known WDT/Map identity mismatch or own retirement→SOURCE_INVALIDATED. No source exception is classified by message/isKnown. Raw scanner malformed/contradictory data and arbitrary provider/runtime/cleanup failures remain FATAL in this first conservative mapping unless a separately reviewed exact pure-parser refusal boundary is added. Direct/bounded standard-wrapped cancellation remains cancellation and preserves healthy registry proof; noncancel proof-validation failure conservatively invalidates ONLY its associated token. Do not invent new origin factories while that contract is active.

## Narrow end-ownership acceptance added after f0 review

Do not reintroduce the old pre-f0 pattern in the new global engine. Required causal fixtures include: real cancel callback waiting for returned R.close then held and throwing; late negative end-future fault after actual declaration callback returned R, held/throwing R cleanup; working remains occupied/no new capture/stat/read before both close+callback drain; both original and cleanup failures remain visible; future create/activate/new borrow fails sticky health and close reports exceptional actual completion. A clean cancellation must not poison a healthy current scope. Also hold a pre-transfer final gate, close the engine after cancellation sealing, and prove no successful R handoff after registry retirement: direct external cancellation and source-close gates must be checked at the transfer linearization independently of whether a sealed dispatcher accepts another request.

The two-proof bound includes replacement construction policy: current+old replacement may coexist before new Map bind, but old replacement is dropped before a new WDT candidate is built. There is no third retained global proof/MAID graph and no automatic rollback to an obsolete pending selection; only the still-current proof can remain presented. A failed validation invalidates only its own token, never a different current token. Temporary Map binder/context and new candidate metadata remain in their named per-operation/control phases, not an extra resident snapshot.
