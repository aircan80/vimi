## Exact output and construction

Traverse qualified layers in recorded header/instance order, cells in local Y-major/X-minor order and only set source mask bits. Every included cell emits four independent vertices NW,NE,SW,SE. Their XYZ are actual recorded anchors plus local sample offsets and the actual constant used source height; depth is the matching unsigned source depth byte. Emit indices `(NW,SW,NE),(NE,SW,SE)`: explicitly the NE–SW diagonal. All four heights are equal, so this does not assert support for nonplanar diagonals. No normals, UVs, material opacity, colors or draw policy are invented.

Empty/unresolved outputs allocate no geometry arrays. Counts are reserved under the existing two-owner construction credit before allocation, while Source active/lifetime remains held. Any allocation/fill/final-check failure retires all unreturned arrays and credit; unknown failures are fatal, not optional liquid coverage.
