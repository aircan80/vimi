# VibeMiner v0.1.0-alpha.3

This is a preview prerelease, not a stable or official release.

- Dungeons: browse the selected build's readable dungeon and raid maps, search by
  name or map ID, and inspect recorded difficulty capacities and entry messages.
- Inspect associated area names, client encounter records and available journal
  descriptions, with a compact source-coverage panel and optional encounter icons.
- Dungeon views follow build readiness and preserve canceled preparation's
  previous workspace; closing a build drains reads before its tables retire.

Readable partial tables remain usable. Associated areas may be dungeon interiors;
these are not entrance coordinates. Encounter records do not promise a complete
boss or loot list. Modern content-tuning numbers are not guessed as entry levels.
No game files are included in the installers.

Choose the asset matching your operating system and CPU. Packages include Java,
JavaFX and SQLite; no separate Java installation is required. Initial installers
are unsigned, and macOS applications are not notarized. Installer creation and
packaged GUI startup are checked on all five targets; installer installation and
uninstallation still need hands-on platform validation. See docs/prereleases.md
for installation, checksums and the native version mapping.
