# VibeMiner v0.1.0-alpha.15

World Explorer now renders its existing height-shaded terrain through the inline
GPU viewer on capable backends. Camera movement and resizing reuse uploaded
geometry. Terrain and model previews share one managed GPU child, with software
fallback, explicit retry and visible loading/first-frame feedback.

Native coordinates, holes, flat height/slope shading and fog remain source-based.
Empty streamed neighborhoods retire stale GPU output and show software sky.
Frames preserve aspect ratio within800×500; nearby terrain discovery stays bounded
while camera controls update independently. Buildings, terrain textures, water,
collision and animation remain outside this terrain slice.

Independent native tests cover full nine-tile upload, depth ordering and actual
World JavaFX presentation/lifecycle. Actual hardware qualification covers Linux
Vulkan. Metal/D3D execution remains unqualified; unsupported depth/capabilities
fall back safely. GPU readback/copy/FX upload remain costs, so a universal speedup
is not claimed. This is an explicit prerelease after all packaged checks pass.
