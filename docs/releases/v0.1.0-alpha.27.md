# VibeMiner v0.1.0-alpha.27

World Explorer now draws real doodads. Before this release, no real doodad was
drawn at all: their texture coordinates were looked up in an M2 table that real
models leave empty. Coordinates now come from each batch's vertex shader, the way
wow.export picks them. Doodads with flag 0x200 and doodads tilted on slopes are
also drawn now. Their rotation follows the convention that TrinityCore and the
wowdev wiki agree on, so trees stand upright on slopes, rocks sit on the ground
and fallen logs lie as placed. The meaning of flag 0x200 is still not confirmed;
it is drawn because no source lets it change the model or its placement. On the
real Azeroth and Elwynn tiles that were checked, 70 to 530 doodads are drawn per
tile, where none were before. Buildings are unchanged. Each tile draws at most
512 doodads. Outdoor doodads are placed first, so on busy tiles most of the
doodads inside buildings are left out, and the status line counts them. Only
Linux Vulkan was checked on real data.

Click a drawn building, doodad or creature to inspect it. The click is tested
against the triangles actually drawn, and see-through surfaces count only where
they are visible. The selection is outlined with a box, and the inspector shows
the object's source records: the model and WMO file IDs, the listfile path or
"name unknown", the placement record and unique ID, the doodad set, and, for
creatures, the NPC, display and spawn records. If a tile's records cannot be
matched to its drawn objects with certainty, every object on that tile shows
"source record unknown" rather than risk naming the wrong one. Clicking terrain,
sky or a spawn marker clears the selection. Water is not picked.

Preparing a library's common tables is faster again. Each generated table is now
saved with one durable commit instead of about four, and the shared library
database commits with SQLite's WAL `synchronous=NORMAL` instead of FULL. On one
Forever build with 1.25 million files and 1,270 tables, building the common tables
from scratch fell from about 82 s to about 39 s (it was 235 s before alpha.24),
with every table ending in the same state. The durability rule is that a power
cut or OS crash may lose the most recent saves but never corrupts the library:
pack data is still forced to disk before the index rows that refer to it, and
compaction, recovery and open/close keep their forced commits. Crash tests kill
the process and simulate the OS losing the end of the write log in dozens of
ways, then check that nothing is corrupt and preparation recovers.

Switching between races and classes you have already viewed is now immediate.
Model variants, previews, voice lists and textured appearances are kept while
the build stays open, and each is checked against the content of the files it
came from. Voices load on their own worker, so they no longer delay the model,
and only one GPU renderer starts per selection. A repeat switch now shows the
textured model in about 0.1 s instead of about 2.7 s, and the GPU frame follows
in about 0.5 s. A first visit is also faster, about 2.6 to 3 s instead of about
4.6 s. A result built while some data was briefly unreadable is shown but not
kept.

Builds recorded under the CN region can download files again. The CN region's
only CDN host is not one VibeMiner accepts, and those builds failed with "No CDN
context was supplied". When a region has no accepted host, a build now borrows
another region's accepted route, but only if that region lists the same build
with exactly the same CDN configuration. Every file is still checked against its
key. The build details then say "CDN route" and name the region used. If no
region qualifies, the error now says so and suggests choosing another region's
listing of the build.

Packaged apps now load JavaFX's native libraries from inside the application
instead of extracting them into the shared `~/.openjfx/cache` folder. Before,
two copies of VibeMiner starting at the same moment on an empty cache could fail
at startup. The Linux `.deb` packages now declare a fixed set of dependencies and
install on Debian 12 and 13 and on Ubuntu 22.04 and 24.04. The alpha.26 `.deb`
packages did not install on some of these.

Diagnostics redact more. Account, realm and character folder names after
`WTF/Account/`, paths encoded in web addresses (even several times), and paths
after brackets, pipes or `#` are replaced in logs and status text. Several World
code paths now report a real failure as a failure, instead of treating it as a
routine cancellation. A building that is drawn only with see-through surfaces
can no longer push a solid building off the tile.
