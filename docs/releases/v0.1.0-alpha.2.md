# VibeMiner v0.1.0-alpha.2

This is a preview prerelease, not a stable or official release.

- Mounts: browse recorded mount appearances and render a selected model from the
  build's original assets. Variant and source-spell evidence remain visible;
  preview files load only after selection.
- Professions: browse recorded profession abilities and recipe facts, including
  reagents, tool references and source tables. Selected item references use
  prepared item names where available. Unknown yield/acquisition stays explicit.
- Build workspace navigation scrolls horizontally on smaller windows.

Readable partial tables are supported. These lists describe the available build
and source records; they do not promise complete server-side acquisition data.
No game files are included in the installers.

Choose the asset matching your operating system and CPU. Packages include Java,
JavaFX and SQLite; no separate Java installation is required. Initial installers
are unsigned, and macOS applications are not notarized. Installer creation and
packaged GUI startup are checked on all five targets; installer installation and
uninstallation still need hands-on platform validation. See docs/prereleases.md
for installation, checksums and the native version mapping.
