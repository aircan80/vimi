# VibeMiner v0.1.0-alpha.14

World area selection now offers **Find terrain**. It explicitly checks terrain
files for that exact recorded area ID, shows checked/total and unavailable files,
and supports cancellation with visible drain activity. Child areas are not
implicitly included, and the full continent grid stays visible.

Choose a matching tile to open at a source-derived, hole-aware chunk entry.
The source content key and entry evidence are revalidated before opening; changed
sources require a fresh search. Partial/canceled scans never claim full zone
coverage. Missing terrain files may be downloaded through the existing service.

Independent parser/backend/GUI reviews, authored asynchronous FX tests and a
private one-tile native source proof passed. World terrain still uses CPU
rendering; GPU terrain is a separate roadmap release. Publication requires all
five packaged platform checks. This is an explicit prerelease.
