# VibeMiner v0.1.0-alpha.19

World Explorer terrain decoding now uses bounded primitive geometry buffers
instead of boxed Float/Integer collections and per-cell temporary arrays. This
reduces allocation pressure during neighborhood loading while preserving source
vertex bits, triangle order, terrain holes and area metadata.

A fixed full-tile fixture allocated about5.3MB per parse instead of13.3MB. Three
private real terrain files produced identical geometry fingerprints, complete area
digests and counts with old/new parsers; their measured allocations fell from
about13.3MB to5.3–6.1MB. These are local parse diagnostics, not FPS or total-memory
guarantees.

This release also includes optional preallocation-bounded prepared-row reads and
a deterministic watchdog cleanup test. Existing source reads remain compatible;
strict limit refusal does not mark a valid prepared graph as corrupt.

Terrain textures remain the BASIC preview profile. Neighborhood changes still
make a cold GPU renderer handoff. Persistent streaming, greater distance,
buildings, instances, NPCs, music and character-creator changes are not enabled by
this release; they continue separately.
