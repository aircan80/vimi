# VibeMiner v0.1.0-alpha.32

This update opens the World Explorer on Anniversary, build 2.5.6.70577. In
alpha.31 it refused every map on that build. Terrain now streams and is
textured on Eastern Kingdoms (map 0) and Outland (map 530), and the recorded
sky, still opt-in, can now be read there too. Classic Era, build 1.60.1.70862,
is unchanged: the same terrain coverage, fill times and sky as in alpha.31.
Library storage did not change: no schema version or table changed since
alpha.31, so an alpha.31 library opens as it is, without migration (#632,
#633, #634).

The changes were measured on real data with the World measurement probe and
covered by unit tests. The recorded-sky GPU proofs pass on Vulkan on Linux.
The owner's on-screen checks on Windows with Direct3D 11 are still pending for
this release and for alpha.31, alpha.30 and alpha.29, and nothing new was run on
Metal; see Known limits at the end.

## World Explorer on Anniversary

- **Maps open.** The Map table on Anniversary has no WDT file field, so the
  World refused every map there. When a reviewed Map layout has no such field,
  the World now finds the map's WDT through the map's directory,
  `world/maps/<Directory>/<Directory>.wdt`, using the build's file names. Only
  the Anniversary Map layout is reviewed for this. Any other layout without the
  field is still refused, with that reason. A layout that has the field but
  not admitted is still refused and never falls back to the directory. A saved
  map binding records which way its WDT was found, and the path is looked up
  again when the binding is checked, so a saved binding never follows the
  path to another file (#632).
- **Terrain textures.** Two terrain textures on Anniversary are paletted with
  8-bit alpha and declare their own handmade mip levels, a combination that
  was refused. It is now admitted with the same checks as the other handmade
  mip chains: every level present, exactly sized, in order and ending at the end
  of the file. Other paletted handmade combinations are still refused (#633).
- **Coverage.** Measured with the probe's refusals mode over every tile:
  - Eastern Kingdoms (map 0): from 0.0% textured in alpha.31 to 98.8% with the
    map fix alone, and 99.9% with the texture fix. 686 tiles are ready and 1 is
    unavailable; the remaining gap is 256 chunks with no texture layers
    (#632, #633).
  - Outland (map 530): from 0.0% to 99.0% textured. 791 tiles are ready, 1 is
    partial with one missing texture, and 8 are unavailable (#632).
- **Fill times.** In the probe's stream mode, all 9 tiles around the camera
  were ready with all their terrain in 2.77 s in Elwynn Forest, 2.52 s in
  Stormwind and 2.00 s in Hellfire Peninsula (#632).
- **Recorded sky.** The Anniversary layouts of the LightParams, LightData and
  Map tables are now reviewed for the fields the sky reads, so the recorded
  sky, fog, light and water light can load there. Before, they stopped with
  "LightParams has a layout that has not been reviewed". In Elwynn Forest and
  Hellfire Peninsula, at 00:00 and at 12:00, the sky at the camera is now
  partial with full coverage, with fog, light and water present. Each table
  only accepts its own reviewed layouts; any other layout is refused as before.
  The sky stays behind `-Dvimi.world.sky=recorded` (#634).

## Classic Era

Nothing changed on build 1.60.1.70862. Before and after these changes the
probe measured the same results: Eastern Kingdoms 95.8% textured, Kalimdor
100.0%, Elwynn Forest filling all 9 tiles in 3.02 s, and the same recorded-sky
results in Elwynn Forest and Stormwind (#632, #633, #634).

## Storage

Library storage is unchanged: no schema, user version or table changed since
alpha.31. Map bindings found through the WDT file field keep the same saved
stamp as before, so they are not rebuilt. The terrain texture decoder revision
did not change: tiles with a refused texture were partial and were never saved
(#632, #633).

## Measurement and tests

- The World measurement probe's stream mode now prints a sky line after the
  fill: the recorded sky at the camera at 00:00 and 12:00, its coverage,
  whether fog, light and water are present, and the light tables' issues, or
  why they were refused (#634).
- New tests cover the directory WDT binding: finding and rechecking it, the
  path moved to another file or removed, the two kinds of binding never sharing
  a stamp, unreviewed layouts, a directory with no WDT, and unusable Directory
  fields (#632).
- New tests cover paletted handmade mip chains: exact colour and alpha at every
  level of a synthetic chain, malformed chains, unreviewed combinations, and
  such a texture reaching a ready terrain tile and the stream packet (#633).
- New tests check that the Anniversary light layouts give the same results as
  the Classic Era ones, that another table's reviewed layout is refused, and
  pin the reviewed layouts of each table (#634).

## Known limits

- **No World creatures on Anniversary.** There is no reviewed source of
  creature spawns for build 2.5.6.70577, so `-Dvimi.world.creatures=true`
  shows no creatures there.
- **Humanoid NPC appearances on Anniversary.** The tables that describe
  humanoid NPC appearances have not been reviewed for that build.
- **Sky rows skipped on Anniversary.** 12 LightData rows are skipped because
  their colour values have a top byte that is set, such as `0xFF242141`, and
  what that byte means on this build is not established. In 10 rows, from two
  parameter sets, the sky colours are unreadable and the whole row is skipped.
  In 2 rows, from two other parameter sets, only the direct and ambient light
  are dropped and the sky and fog are kept (#634).
- **Other layouts.** Only the Anniversary Map, LightParams and LightData
  layouts named above were added. Other classic layouts are refused until they
  are seen and reviewed (#632, #634).
- **Owner checks on Windows.** The Anniversary changes were measured with the
  probe and covered by unit tests. These on-screen checks on Windows with
  Direct3D 11 are still pending:
  - on Anniversary, World Explorer opening on Eastern Kingdoms (Elwynn Forest,
    Stormwind) and Outland (Hellfire Peninsula), with terrain streaming and
    textured (#632);
  - on Anniversary, Elwynn Forest and nearby Eastern Kingdoms tiles with no
    untextured terrain chunks where they were partial before (#633);
  - on Anniversary with `-Dvimi.world.sky=recorded`, the sky, fog and terrain
    light following the recorded light in Elwynn Forest and Hellfire
    Peninsula, also with `-Dvimi.world.sky.time=00:00` (#634);
  - on Classic Era, nothing changing (#632, #633, #634).

  Carried over from alpha.31 and still pending:
  - glow-only creatures appearing as soft glows that add light, with no dark
    boxes or fully opaque quads; glows on creatures that already drew, with
    nothing showing that the client hides; and unlit glows that look too
    bright at night (#623);
  - translucent creatures and parts with no dark halos, fully opaque quads or
    parts showing through solid geometry; lit blended parts by day and at
    night; and blended parts of one creature flickering or popping in front of
    each other as the camera turns (#625);
  - partially faded glows and veils looking as bright or as faint as in the
    client's idle, with no dark or black halos; creatures that were missing,
    such as spirits, wisps and elementals, now appearing; and nothing showing
    that the client hides in idle (#628).

  Carried over from alpha.30 and still pending:
  - creatures that used to stand frozen now idling, with nothing jumping,
    flipping, exploding or tilting, including alias Stands, bone-file rigs and
    skeleton rigs (face and hands) (#607, #609, #614, #615);
  - glow cards pulsing or drifting while staying camera-facing in the previews
    (#616);
  - World creatures with flames or glows standing with those parts left out
    (#618);
  - World creatures that were missing now drawn with their base texture, and
    how far the missing shine, tints and fades show (#620);
  - upright sprites in the preview from eye level and from above (#619);
  - switching between Near and Far on the Display page, the remembered choice,
    and the disabled choice with the launch flag (#611);
  - Far filling smoothly and clicking an outer-ring tile naming the zone
    (#608);
  - the zone text and its music right at spawn (#610).

  Carried over from alpha.29 and still pending:
  - the stretched non-square textures and the formerly untextured tiles (#576,
    #572);
  - water and lava: recorded ocean and river colours, coasts, and opaque lava,
    fel and tar (#586, #594);
  - the recorded light on terrain, objects and the horizon, by day and at night
    (#591, #592, #597);
  - glass and water panes in one object drawing in the right order (#574);
  - creatures' body parts under the new geoset default (#599);
  - the recorded sky in native window presentation (#567), whose proof has not
    been run on Windows yet;
  - splat blending with `-Dvimi.world.splat=true`: the fade band staying put
    while turning, no seam from a neighbouring chunk, and no tiles stuck
    untextured on the high tier at Near (#581, #583);
  - ambience starting without an extra pause when flying between zones (#578).

  The Metal shaders are built, and nothing new was run on macOS hardware.
- **Creatures still in the rest pose.** In the previews, billboard bones with
  child bones or rotation keys, members not rigidly bound, lock-X cards and a
  few parent-inheritance flags still refuse the Stand. In the World, 3 models
  with ignore-parent flags and the two models above the bone limit stay in the
  rest pose. Models whose Stand records no bone keys show their rest pose
  (#384).
- **Creatures not drawn in the World.** On Classic Era, 86 of 1,050 census
  models still have no surface the World can draw, as in alpha.31 (#361, #384,
  #628).
- **Glow and blended parts in the World.** Colour tracks are not applied as
  tints or alpha, so a blended part can draw more opaque than in the client.
  Glows are drawn unlit, so glow batches not marked unlit draw brighter at
  night than in the client. Blended parts sort per part within a creature.
  Fading weights are taken at time 0 of Stand (#361, #623, #625, #628).
- **Bone files** are not applied for character displays, and `.anim` files and
  parent skeletons are not read (#384).
- **Sun direction.** The light's direction is still fixed. The light tables
  record colours, not a direction, and the client's sun path is not pinned yet
  (#177).
- **Water depth.** The shallow-to-deep mix reads the depth byte linearly; the
  client's exact curve and water textures are not used yet (#594).
- **View distance.** Near stays the default; whether Far becomes the default is
  not decided (#173).
- **Opt-in features.** These are Java system properties for testing, not
  settings in the app yet:
  - splat blending: `-Dvimi.world.splat=true`;
  - the recorded sky, fog, light and water light: `-Dvimi.world.sky=recorded`,
    with `-Dvimi.world.sky.time=HH:MM` to pin a time;
  - creatures: `-Dvimi.world.creatures=true`;
  - WMO vertex colours: `-Dvimi.world.wmoVertexColours=true`;
  - high object texture detail: `-Dvimi.world.objectTextures=high`;
  - native presentation into a child window, on Windows only:
    `-Dvimi.world.nativePresent=true`.

  `-Dvimi.world.viewDistance=far` still forces the Far view distance. Terrain
  lighting is on and can be turned off with
  `-Dvimi.world.terrainLighting=false`.
- **Outland and Northrend on Classic Era.** Maps 530 and 571 are not in build
  1.60.1.70862. Outland is measured on Anniversary only, and Northrend was
  not measured.
- **NPCs.** On 1.60.1.70862, few spawned NPCs have a Creature record, so few
  reach a display, as in alpha.31.
- **macOS:** packages are unsigned and not notarized, and native presentation is
  not available. The signature check on `--image-only` builds was tested with
  `codesign` stubbed and has not been run on a Mac yet (#568).
- **Linux:** packages need the standard GTK and X11 desktop libraries, and native
  presentation is not available. The deb dependencies added in alpha.29 were
  not tested with a clean install.
