# VibeMiner v0.1.0-alpha.5

This prerelease adds reviewed Orc male and female static character textures and
recorded class clothing to Races. The existing Human profiles remain available.
Only the reviewed Orc model/sex/texture-layout pairs are admitted; other race
texture profiles remain explicitly unsupported.

An appearance-selection fix preserves base body/scalp geometry when a bald or
other hairstyle is chosen. Previously an unselected bald alternative could remove
body geometry, including arms and hands. Restored texture previews now retain the
warning when some draw surfaces use neutral shading.

Actual Forever 1.60.1.70707 source validation covered both Orc variants with
recorded Warrior and Warlock clothing, including the robe geometry and selected
texture decoding. The preview remains static: animation, full lighting shaders
and separate held equipment are not evaluated. Samples do not establish account
unlock eligibility or the client's default customization choices.

The derived appearance policy changed; affected previews are regenerated once
through the existing build-owned storage. No storage-format migration or original
CDN-content deletion is introduced by this change.

Validation includes 25 deterministic Races component tests, formatting and
Checkstyle. Platform packaging and smoke checks must succeed before publication.

Build search/status filters now keep Open build aligned with a visible result.
No matches clears the selection, and retained identities use the newest row facts.
