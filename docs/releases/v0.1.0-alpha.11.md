# VibeMiner v0.1.0-alpha.11

Model previews now prefer hardware GPU rendering inside the existing JavaFX
viewport, using LWJGL and bgfx. Unsupported or failed renderers fall back to
software. Hidden viewers release their renderer. Loading activity is visible
while scenes and appearance data are prepared.

Files, Tables, Items and Creatures gain local loading indicators, retained rows
during updates, and background icon conversion. NPC/Quest browsers retain rows
during updates and show local loading. Races adds local catalog/model/appearance
activity and background racial-icon conversion. The remaining activity audit is
in docs/gui-loading-audit.md.

Inline rendering uses bounded GPU readback, shared-memory copying and JavaFX
image upload. It is not zero-copy. Authored Linux Intel/Vulkan proofs cover
materials, camera changes, resizing, cleanup and software fallback; this is not
a universal performance claim. Actual Metal/Direct3D hardware rendering remains
unverified. Native-library and packaged-shader checks run across supported
platforms. Static diffuse preview support does not include animation or complete
WoW materials.

This release also includes audited native table text-issue certificates for
comparison. Legacy/custom uncertainty and uncertified membership remain intact.
Build Comparison #117 remains open.

Independent scoped reviews, full local checks, all platform unit/integration
checks, compatibility checks and pinned shader verification passed. Packaged GUI
and native-runtime checks must pass on all five targets before publication.
This remains an explicit prerelease.

Alpha.10 was reserved by a tag before its notes were committed and was not
published; that tag is preserved.
