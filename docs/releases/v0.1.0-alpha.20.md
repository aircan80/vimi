# VibeMiner v0.1.0-alpha.20

Explore selected-build world map artwork in the new Maps tab. Start at Azeroth
where recorded, open continents and zones, use Back, Up and breadcrumbs, or switch
maps directly. Wheel zoom, drag pan and Fit retain view state. Overlapping recorded
areas offer a chooser rather than silently selecting a zone.

Hierarchy and artwork load off the UI thread with visible activity through image
completion and readable tile counts. Source details include unavailable artwork
reasons. Prepare map tables explicitly prepares the selected hierarchy when older
saved evidence is insufficient; missing source files may download. Existing legacy
graphs and held captures remain unchanged.

Authored UI/lifetime checks and independent reviews pass. An actual selected
wowf70755 proof browsed Azeroth, Eastern Kingdoms and Elwynn with all12 recorded
artwork tiles for each map, correct Back/Up/direct navigation and clean shutdown.
The original library stayed read-only during that proof; acquisition and preparation
writes stayed in private scratch. No game artwork is included in the release.

This release also adds bounded raw WDT global-scene facts for future instance
support. It does not yet display global-model dungeons/raids. Map click regions
are recorded assignment rectangles, not zone polygons; dungeon floors, quest/NPC
markers and current-character phase evaluation remain future work.

World terrain uses the existing BASIC texture preview and cold neighborhood
renderer handoff. Persistent streaming, larger distance, buildings, water, NPCs,
area music and character customization continue separately.
