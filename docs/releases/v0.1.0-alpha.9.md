# VibeMiner v0.1.0-alpha.9

Compare adds recorded Items facts from existing prepared Item and ItemSparse
snapshots. Quality IDs, classification/inventory type, recorded levels, ordered
flags and available names retain their source identity. Conflicts and uncertain
cells remain visible; partial readable rows are useful without certifying whole
build membership.

Streaming joins preserve independent source halves. Shared temporary-file quotas,
compact held metadata, bounded candidate reads and paged session findings keep the
comparison working-buffer policy intact. No graph repair, payload download or
ordinary per-item lookup is performed by comparison.

Coverage details expose captured identities, assessed fields and global omissions
even when no findings exist. Selecting a pair or area does not start comparison;
use Compare local data explicitly. Old/custom cached graphs with null issue
channels retain text uncertainty. Effects/use/equip text, assets, full gameplay
semantics and persistent reports remain unassessed; #117 stays open.

Independent architecture/data reviews, 154 comparison unit/adapter tests, pure
projector checks, native SQLite/pack composition and authored JavaFX checks pass.
The native fixture verifies missing dependencies, unsigned maximum IDs and zero
acquisition/object/readiness writes. Platform CI and packaged checks must pass
before publishing. This remains a prerelease.

Also includes the deterministic captured-delivery cancellation test fix; production
capture behavior is unchanged.
