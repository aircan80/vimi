# VibeMiner v0.1.0-alpha.17

World Explorer batches neighboring cell arrivals before replacing its terrain
scene. Camera updates continue on the active GPU scene while source files load,
and the last readable image stays visible during the replacement. A full
three-cell boundary strip now prepares one replacement instead of publishing
intermediate trimmed and partially filled scenes. Incoming cells replace only
outgoing cells, avoiding unnecessary reloads on negative-axis movement.

A replacement waits until the active GPU scene has presented its first frame or
ended, so rapid source arrivals do not repeatedly starve presentation. Missing
sources keep usable coverage with loading retired; truly empty/far-away coverage
still switches to sky. Existing geometry, source, frame and child-process limits
remain unchanged. One cold scene replacement can still cause a pause; this is a
reduction in replacement churn, not a zero-gap or universal FPS guarantee.

Races keeps a visible texture/composition badge over the neutral model while
appearance preparation runs. It clears only when a frame for the target
appearance is accepted in the current display mode, or when a clear terminal
error is shown. Stale selections cannot clear newer activity. Partial appearances
are labeled accordingly; intentionally turning Textures off does not strand the
indicator.

This release keeps the existing nearby view distance and height shading. Greater
view distance, terrain textures, scenery and water continue separately. Actual
native rendering evidence remains Linux Vulkan; this is an explicit prerelease
subject to all packaged checks.
