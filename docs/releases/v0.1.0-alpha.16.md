# VibeMiner v0.1.0-alpha.16

World Explorer now follows the correct terrain neighborhood while flying across
native world coordinates. The previous camera lookup swapped the two filename
axes, which could unload the terrain being approached, show blue sky after a
loading indicator, and restore it only when moving back. The continent tile-grid
orientation remains unchanged.

Space or E raises the camera; Q lowers it. Holding Space and E together keeps the
same ascent speed. Click the viewport to focus flight controls.

Maps with no recorded terrain or unavailable terrain inventories now explain
what is missing in the map panel. Maps positively recorded as global world models
explain that their model preview is not available yet. Explorer and area-discovery
actions are disabled when there are no terrain tiles to use.

The terrain view remains a bounded nearby neighborhood with height shading.
Greater view distance, minimap artwork, terrain textures, buildings and water are
separate work. Existing GPU fallback and backend qualification limits remain.
This is an explicit prerelease; publication requires all packaged checks.
