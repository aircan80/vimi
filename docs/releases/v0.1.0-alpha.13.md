# VibeMiner v0.1.0-alpha.13

Mount previews now support reviewed reflective two-texture armor, unlit detail,
additive effects and camera-facing rigid cards on both CPU and inline GPU paths.
This corrects Black War Raptor and Great Brown Kodo static previews. Unknown
material profiles remain explicit; animation and particles are not evaluated.

The World continent tile grid now has the correct orientation. Areas and zones
remain reference information for the full continent grid. World terrain still
uses CPU rendering.

Generated model previews use a revised material policy and bounded appearance
codec; stale derivatives rebuild from original source assets. Existing legacy
appearance APIs remain supported. Optional source-fact failures preserve usable
sections without saving incomplete derivatives.

Independent scoped review, source failure fixtures, 30 authored native GPU cases,
36 private live CPU/Vulkan comparisons and JavaFX inline checks passed on Linux.
Actual Metal/D3D hardware rendering remains unqualified. Publication requires all
five packaged platform checks. This is an explicit prerelease.
