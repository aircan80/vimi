# VibeMiner v0.1.0-alpha.18

World Explorer gains **BASIC terrain textures** on GPU and in the software
fallback. Supported terrain uses a bounded diffuse atlas with source tint and
fog. Missing, protected or unsupported inputs keep height shading with an explicit
status and texture retry action. This first texture profile approximates blending;
it does not implement the client's height blending or nonlinear sharpening.

Terrain geometry and its available textures now prepare together before a
neighborhood is replaced. The previous readable scene remains usable while the
replacement loads, reducing material pop and redundant replacements. Activity
continues through preparation and upload until the target frame is accepted or a
clear fallback is presented. Initial loading waits for the available nearby
neighborhood rather than repeatedly replacing partially prepared scenes.

The explorer now shows the recorded terrain **zone and subzone** as you move.
Missing or ambiguous area data stays explicit; indoor building-volume areas are
not resolved. X or Q descends, while Space or E ascends. The wheel moves forward
or backward along the view direction, including pitch; Shift+wheel changes flight
speed. The minimap offers North up and Heading up orientations.

A top-right **VibeMiner mining indicator** shows measured HTTP response-body rate
and the total received this application session. It covers the default build,
metadata and source-download paths, including Questie. Details distinguish
waiting, reading and an open transfer handed to local code. Idle and reduced-motion
states stay static; cache hits, local preparation and rendering do not manufacture
network traffic or replace their own progress indicators.

Talents' collapsed **Source details** now explains missing images and descriptions
using the available file/decoder and source outcomes. Unreported causes remain
unknown; expanding the explanation does not start another source query.

Item #286556's “Desert Winds” description now resolves the supported 50%, 10 sec and 80%
values instead of displaying raw substitution tokens. Raw text and substitution
evidence remain in Source details. This adds narrowly reviewed static percentages
and fixed durations, not character scaling or gameplay/script evaluation.

Nearby view distance is unchanged. A scene replacement still makes a **cold GPU
handoff** and can pause; persistent streaming remains a separate prototype, not an
enabled release feature. Greater distance, buildings/doodads, water and the
hierarchical Maps browser remain follow-up work. Actual native rendering evidence
covers Linux Vulkan; Metal/D3D hardware validation remains outstanding. Publication
of this explicit prerelease remains subject to the packaged checks.
