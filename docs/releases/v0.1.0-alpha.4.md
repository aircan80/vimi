# VibeMiner v0.1.0-alpha.4

This is a preview prerelease, not a stable or official release.

- NPC details show recorded locations on Blizzard zone-map artwork.
- Quest details show explicit pickup/starter locations on the same map panel.
- Switch maps when source observations span several zones. Hover markers for
  provider, snapshot, recorded phase and coordinate/projection evidence.
- Blue markers represent declared spawns; amber markers are approximate observed
  player interaction positions. Unknown or ambiguous positions remain unplotted.

The panel uses enabled, already prepared Questie, Polestar and EG Link snapshots.
Blizzard artwork uses the selected build's normal file pipeline and persistent
image cache. Partial/unavailable source facts and tiles retain readable results.
Base artwork does not evaluate player phase, unlocks or current visibility. Item
quest starters do not acquire invented pickup coordinates.

Packages include Java, JavaFX and SQLite. Initial installers are unsigned and
macOS applications are not notarized. Packaged GUI startup is checked on all five
native targets; installation/uninstallation still needs hands-on platform testing.
See docs/prereleases.md for installation and checksums.
