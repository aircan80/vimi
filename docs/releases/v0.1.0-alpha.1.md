# First desktop prerelease

This is an early testing build of VibeMiner, packaged with Java and SQLite.

- Browse and prepare Blizzard builds with persistent local storage and size accounting.
- Manage/update the supported GitHub data sources.
- Browse items, client creature records, merged NPCs and quests with source details.
- Explore Classic talent trees and race information, recorded voices and reviewed
  Human class appearance previews.
- New World area: choose a continent/map and terrain tile, then fly around real
  terrain with bounded nearby-tile streaming.

World currently uses height shading; buildings, terrain texture painting, water
and collision are not rendered. NPC/quest zone-map markers, Dungeons, Mounts and
Professions are subsequent milestones. Protected or unavailable data remains
explicitly incomplete. Race class clothing profiles currently focus on Human;
animation and held equipment remain follow-ups.

Install the asset matching your operating system and architecture. Windows MSI is
per-user and needs no separately installed Java/SQLite. Portable archives are also
provided. These prerelease installers are unsigned; macOS packages are not
notarized. Platform security prompts may require a manual open/install decision.

Every release asset has a SHA-256 entry in SHA256SUMS. The per-platform manifest
records its source commit, bundled SQLite hash and packaged-runtime smoke result.
