# VibeMiner v0.1.0-alpha.6

This prerelease introduces the first Build Comparison slice. Compare opens a
separate workspace beside Builds. Select two locally prepared builds of the same
product and locale, choose Files or Tables and select Compare local data.

Files compares selected-locale content keys and decoded sizes. Current names and
live downloaded state are unassessed. Files membership coverage remains unknown,
so unmatched observations are not presented as proven game-wide additions or
removals. Tables compares the exact cached known-definition preparation inventory;
it does not compare table rows, full schemas or every game table.

Results are session-only, paged and bounded. Known-equal records are omitted from
the findings list; scanned counts are distinct from change counts. Search and
status filters apply to the current page. Coverage reasons and per-field evidence
remain visible. Other areas are explicitly marked Not implemented.

Comparison opening and reads use local-only capabilities without refreshing
providers or acquiring missing Blizzard payloads. Missing prepared input produces
an explanation rather than hidden preparation. Leaving Compare cancels and drains
the pair without closing an unrelated browsed context. Reports are not persisted.

Validation includes 35 comparison component/adapter tests, coordinator lifetime
and forbidden-network native fixtures, complete GUI checks and authored JavaFX
screen checks. Native CI and packaged startup checks must pass before publication.
This is a Foundation milestone for #117, not completion of semantic comparisons.
