# BASIC WMO source factory checkpoint

This implements the source-only milestone of the approved c2ec2ca/1378984 design. `WorldBasicWmo` is package internal and adds no BuildWorld, service-constructor, GUI, packet or renderer API. It uses the live `WorldStreamScopes` BASIC_WMO admission from 8100e1f. Selection carries only map/tile selector and MODF ordinal/expected unsigned UID; all dependency IDs, material operands and transforms come from actual admission-owned bytes.

The chain is actual ROOT ADT→canonical geometry SHA, actual OBJ0→unique checked MODF, actual direct WMO root→sole GFID→group→deduplicated material texture1 BLP images. Root bytes/grid leave scope before OBJ0; OBJ0/unselected records leave scope before WMO/image reads. The source engine reserves one live raw input and revalidates every consumed identity after the trusted output callback. WDT provenance is included in the detached binding list. Known declared lengths and actual enforced source limits are preserved separately; unknown before-read lengths remain null under the reviewed source engine contract, and actual bounded streaming remains mandatory. This supersedes the earlier proposal's unknown-size refusal sentence; it grants no larger byte limits.

The structural policy has no asset-ID whitelist. It admits only the documented modern GFID/no-MOTX, one-group, opaque shader0/one-texture profile. Every recorded batch must partition the complete index inventory; unsupported chunks/materials/MOCV/water reject the entire candidate. Empty MODS declarations are checked against their actual body, not merely their descriptor size. Source normals must already be unit within0.001 and are normalized in double before one float cast. Local positions, UVs and indices remain recorded; the explicit ADT heading matrix uses StrictMath and double translation. Root ambient and named material lighting words are preserved through the borrowed raw materials and deliberately ignored by the BASIC preview recipe.

Private-constructed callback borrows and scene matches are worker-thread-only and expire on success or exception. No raw source/capture/engine/input handle is exposed. Read-only NIO views are synchronous contractual borrows; Java cannot revoke a previously returned primitive view. The output callback is trusted to own partial/unreturned allocations with try/finally and may return only unadvertised owned output. The engine owns the returned result through final all-binding checks and closes it on staleness/cancellation. This helper creates no persistent cache, worker queue, current/pending asset slots or public positive factory.

Exactly one selected public scene tile must match the actual private root geometry SHA. The existing other eight tiles retain their previous contract and view distance. Whole serialized scene SHA, annex body digest, actual written-file verification and any positive native renderer representation are **not implemented** here; they remain the separately reviewed cold packet/renderer gate. Callback output cannot advertise a packet/child before successful engine transfer. There is no claim of visible buildings, client lighting parity, global instance transforms or runtime allocation/native ownership proof.

## Validation

`JAVA_HOME=/usr/lib/jvm/java-25-openjdk ./gradlew :concepts-world:check` passes all module tests, formatting and Checkstyle. Ten authored factory tests exercise the actual native Map certificate/reader through AuthoredNativeMap and source admission, the complete recorded asset chain, BC1 pixels, asymmetric four-cardinal heading/scale oracles, preserved winding, expiring/thread-bound read-only borrows, unsupported reference/material/normal/batch/chunk/image profiles, duplicate or stale MODF UID, forged public terrain geometry, before-open derived source size limits, callback exception/retry, cancellation, and held-output identity changes to each of WDT/rootADT/OBJ0/WMO/group/image. All source bodies are authored binary fixtures; no live service is required. Separate engine tests cover the larger source-close/drain and fresh Map receipt machinery.

Causal negative controls remove (individually) actual selected terrain geometry equality and material-word qualification; the corresponding authored refusal tests fail. Production source is restored and the complete module check reruns afterward. Logs are private `/tmp/vimi-wmo-source-negative-{geometry,material}.log` and `/tmp/vimi-wmo-source-restored-check.log`.

An actual selected-build factory proof is pending the independently reviewed observed-row partial Map admission change: the real Map capture is genuinely VERIFIED_NATIVE but has encrypted excluded rows (73/81 observed). This helper does not relax that source gate. Existing raw-parser/source investigations establish the recorded exterior sample, but do not substitute for a successful factory transaction. Native codec/shared reversed-depth framebuffer/fog/material shader and actual allocation budgets remain separate gates before a visible-city release.
