# Bundled sample item icons

These eight unmodified 56×56 JPEGs were retrieved from Blizzard's public icon
renderer on 2026-11-01. Artwork © Blizzard Entertainment. They are sample visual
assets, not original VibeMiner artwork or decoded data from the selected build.
Item names, classifications, statistics and tooltip text are separately authored
mock examples; no actual-item identity is asserted by pairing them with this art.

Source URL pattern:
`https://render.worldofwarcraft.com/us/icons/56/<name>.jpg`

- `inv_sword_04`
- `inv_chest_cloth_17`
- `inv_shield_04`
- `inv_potion_51`
- `inv_misc_bag_08`
- `inv_misc_gem_ruby_02`
- `inv_scroll_03`
- `inv_helmet_03`

Assets are bundled for offline display. The running GUI does not contact the
renderer, any game service, or backend layers. Images are cached per view and
rows are virtualized; this fixture has ten item rows plus one detail image.
