# VibeMiner logo

`vibeminer.png` is an unchanged copy of the original 512×512 RGBA export at
`vibeminer/branding/icons/vibeminer.png` in the sibling C# project. Its canonical
vector is `vibeminer/branding/vibeminer.svg`; the sibling's
`docs/migration/java-reference.json` records the original Java artwork provenance.
The original project artwork is GPL-3.0-or-later, as documented in its branding
README and this repository's root LICENSE.

SHA-256: `69b356899ca6bb3bb15c5af265cb91abb21cf141389908aa92e3316ffc356daf`

JavaFX renders the original PNG at 36×36 logical pixels in both screen headers
and uses it as the stage icon. The wordmark is text: dark “Vibe”, teal “Miner”,
22px bold, enlarged from the C# screenshot's branding for this prototype.
