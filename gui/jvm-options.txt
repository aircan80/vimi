# Desktop app JVM options, shared by `gradlew :gui:run` (gui/build.gradle) and the packaged
# app (scripts/release/package_app.py). One option per line; '#' starts a comment.
#
# Low-pause collector: the World explorer presents up to 60 frames a second, so a long
# stop-the-world pause shows as a visible hitch. ZGC is generational on JDK 25.
-XX:+UseZGC
# JavaFX pulses (AnimationTimer, layout, frame presentation) at up to 120 Hz instead of 60, so
# high-refresh displays are not capped at 60 and a 60 Hz display picks up a new frame sooner.
-Djavafx.animation.pulse=120
